# Prisha SDG 14 Web Version

This project remakes the original MIT App Inventor `.aia` app as a web app.

## What is included
- Two app screens equivalent to `Screen1` and `Screen2`
- Web speech synthesis replacing App Inventor TextToSpeech blocks
- Navigation between screens (`Next` / `Back`)
- iPhone 16-style front screen mockup container
- A simulator tour button that auto-plays the app flow

## Run locally
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173`.
